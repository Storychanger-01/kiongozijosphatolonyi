# Hon. Josphat Olonyi – Official Campaign Website

**Emabungo Ward MCA Aspirant 2027 | Vihiga County, Kenya**

---

## Overview

Complete multi-page, modern, responsive and functional campaign website built with the **Emabungo Forward** colour palette.

### Colour Palette
- Primary (Deep Forest Green): `#0B3D2E`
- Primary Light: `#1A6B4A`
- Secondary (Warm Terracotta): `#C45C26`
- Accent (Soft Gold): `#D4A84B`
- Background (Warm Cream): `#F8F4EC`
- Surface (White): `#FFFFFF`
- Text Dark: `#1C2526`
- Text Muted: `#5A6A6C`

## Features

- Fully responsive (mobile-first)
- Sticky navigation + mobile hamburger menu

- Working front-end forms (Volunteer, Contact, Donate) with success messages
- Smooth animations
- Consistent design system across all pages
- Easy to customise and host

---

## How to Use

1. **Open locally**  
   Open `index.html` in any modern browser.

2. **Host online**  
   Upload the entire folder to Netlify, Vercel, GitHub Pages, cPanel, or any static host.

3. **Customise**
   - Replace placeholder images/portraits with real photos of Hon. Josphat Olonyi
   - Update phone numbers, email, WhatsApp and social links
   - Add real news articles, event dates and gallery photos
   - Link the Manifesto PDF download
   - Connect forms to Formspree / Netlify Forms / Google Sheets / custom backend for real submissions
